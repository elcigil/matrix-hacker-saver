Matrix Hacker Saver

// Windows icin Matrix tarzi ekran koruyucu

Siyah zeminde yukaridan asagi akan yesil Matrix kodlari ve ekranin altinda akip giden, hacker filmlerindeki konsol cikti taklidi. Tamamen gorsel amaclidir; gercek bir saldiri veya tarama yapmaz, agla hicbir baglantisi yoktur.

Ozellikler

  • Rakam, harf ve katakana karakterlerinden olusan yagmur efekti
  • Sahte msf6 > / [+] / [*] tarzi terminal satirlari
  • Birden fazla monitor destegi
  • Fare, klavye veya tiklama ile kapanir
  • Tek dosya, ek kurulum gerektirmez (.NET Framework)

Kurulum

  1. Releases sayfasindan MatrixSaverSetup.exe dosyasini indir ve calistir (yonetici izni gerekmez, 5 dk bostan sonra baslar).
  2. Kaldirmak icin: %LOCALAPPDATA%\MatrixHackerSaver\Uninstall.exe /uninstall
  3. Elle kurmak istersen MatrixSaver.scr dosyasina sag tikla → Install.
  4. Ayarlar → Kisisellestirme → Kilit ekrani → Ekran koruyucu bolumunden sec.

Kaynaktan derleme

csc /target:winexe /out:MatrixSaver.scr ^
    /r:System.Windows.Forms.dll /r:System.Drawing.dll MatrixSaver.cs

csc.exe Windows ile gelir: C:\Windows\Microsoft.NET\Framework64\v4.0.30319\

Ozellestirme

MatrixSaver.cs icindeki Lines dizisini duzenleyerek terminalde akan satirlari degistirebilirsin. Karakter seti Glyphs, hiz ve uzunluk NewDrop icinde.
